# HuskyLens Smart Recycling Bin – 3D Model

This repository contains a **3D printable recycling bin model** prepared as part of a 3D modeling task.

## Project Purpose

I selected this model because I plan to use it later in another project related to **HuskyLens**.

The future project will be a **smart waste sorting system** where HuskyLens will be used to identify and classify different types of waste, such as:

* Plastic
* Paper
* Metal

Each type of waste will have its own recycling bin, and **servo motors** can be used to control the opening of the appropriate bin based on the classification result.
